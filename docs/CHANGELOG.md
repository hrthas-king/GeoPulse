# 更新记录

## v0.1.2 — 2026-10-10

- 使用用户提供的蓝绿定位心跳图案作为 Windows 应用图标，嵌入 amd64 / arm64 EXE。
- 交付多尺寸 `assets/GeoPulse.ico`、原始 PNG、资源配置和可复现的图标生成脚本。
- 图标资源随源码保存，普通构建和 Release 交叉编译会自动包含图标，无需安装额外工具。
- 托盘继续显示国家代码、网络状态和流量指示。

## v0.1.1 — 2026-10-10

- 修复国家代码、状态点与上下行箭头上下倒置。新增真实 HICON 像素回读测试，覆盖 Win32 图标创建路径。
- 修复 TUN 切节点但网卡/IP 未变时长期不更新地区：本地代理配置、TUN 状态及常见代理内核 TCP/UDP 端点变化会请求定位；专有客户端无可观察信号时，每 30 秒复核一次。
- 手动刷新采用 2 秒合并间隔，清除旧定位并拒绝迟到结果；自动刷新仍限制为最短 30 秒。
- 定位改用域名并跟随系统代理/路由，每次关闭 keep-alive，避免复用旧出口连接。
- 本地 socket 变化仅请求复核，不再清空有效位置，避免普通代理流量导致国家代码反复变为 `--`。
- 支持 `--quit` 请求旧版本正常退出，方便替换运行中的 EXE。

心跳与网卡采样继续固定 1 秒，公网 IP 接口没有每秒轮询。TUN 节点名称由客户端定义，显示的国家仍以实际 HTTPS 出口 IP 的定位结果为准。
