| 60 秒时线程数 | 10 |

按私有工作集计，本机样本低于 10 MB；按总工作集或私有提交量计，**10 MB 要求尚未达成**。这次短期实测不构成其他机器或长时间运行的硬上限保证。代码分别暴露三种口径，避免误报。

**不能宣称整个进程始终低于 10 MB。**Go 的 `SetMemoryLimit(8 MiB)` 是 Go runtime 软目标，不包含 Win32 / WinHTTP / TLS 内存。私有工作集、含共享页面的总工作集和私有提交量是不同口径，不能混用，也不以清空工作集的方法人为降低读数。

## 手工验收步骤

1. 启动 EXE，确认无控制台或任务栏窗口，托盘折叠区可见图标。
2. 悬停，确认 IP、国家、上下行速率、RTT；下载 / 上传正常用户文件时观察速率与两侧箭头。
3. 关闭网络，约两个心跳周期后确认红色 `--`；恢复网络后确认绿色并触发低频定位。
4. 切换 Wi-Fi 或 VPN 默认路由，确认旧 IP 先清除、新定位到达后更新，冷却内连续事件不会洪泛。
5. 选择 5s 显示，确认心跳仍是 1s，断网状态仍即时推送。
6. 连点刷新 IP，确认 30s 内只合并请求，菜单操作不卡住监控。
7. 手动切换自启，检查 HKCU 的 `Software\Microsoft\Windows\CurrentVersion\Run\GeoPulse` 是带引号的当前 EXE 路径；关闭后该值删除。
8. 退出后确认进程消失；重新启动与移动 EXE 后检查自启指向需要的路径。

原始本机诊断输出含公网 IP，留在 `.artifacts/`（Git 忽略），不发布到仓库。
